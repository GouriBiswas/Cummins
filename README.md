# Rocker Height Project

## Overview
The **Rocker Height Project** is a software application designed to efficiently calculate and manage rocker height data. It provides engineers with a user-friendly interface for real-time data analysis and integrates seamlessly with an **Oracle 12 database** to ensure reliable data storage and retrieval. This project was developed using **Visual Basic** during an on-site internship.

## Features
- **User-Friendly Interface**: Intuitive design for easy data entry and visualization.
- **Real-Time Data Analysis**: Provides accurate calculations and reports instantly.
- **Database Integration**: Uses **Oracle 12** for secure and efficient data management.
- **Error Handling**: Ensures data accuracy and minimizes calculation errors.
- **Pass/Fail Indicator**: 
  - If the height **passes** the set criteria, it is highlighted in **green** with an **OK** status.
  - If the height **fails**, it is marked in **red** with a **NOK** status, allowing for easy identification and correction.
- **Export & Reporting**: Generates reports and allows data export for further analysis.

## Technologies Used
- **Programming Language**: Visual Basic
- **Database**: Oracle 12
- **Development Environment**: Visual Studio


## Usage
1. **Enter rocker height measurements** manually or import data.
2. **Analyze results**:
   - If the height is correct, it displays **green** and **OK**.
   - If the height is incorrect, it displays **red** and **NOK**, allowing users to edit and correct the data.
3. **Generate reports** and export data for documentation.
